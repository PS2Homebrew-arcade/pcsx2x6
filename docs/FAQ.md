# Frequently Asked Questions

## Will this be merged to official PCSX2?

NO

## How can I play Namco System147 and System148 games?

PCSX2x6 does not support system14x and never will, please refer to the [IRIS emulator](https://github.com/allkern/iris), that has experimental support for system14x boards

> system14x is the one with the most radical changes compared to regular PS2s, running homebrew on it is quite hard, and these boards aren't as common as system2x6. please consider supporting [allkern](https://github.com/allkern) so he feels "motivated" to pump more love into sys14x preservation

## How can I play KONAMI PYTHON games?

PCSX2x6 does not support PYTHON1 games and never will, please refer to the amazing [PCSX2_Reliquary](https://github.com/DiscoStarslayer/pcsx2-reliquary) project, which brings support for this platform


## How can I play KONAMI PYTHON 2 games?

PCSX2x6 does not support PYTHON2 games and never will, please refer to the amazing [PCSX2_Reliquary](https://github.com/DiscoStarslayer/pcsx2-reliquary) project, which brings support for this platform
