# Taiko Drum Master 11 - Asian Edition

!!! note "Regional Lock"

    This game expects to find the following "regional signature" at the iLinkID area of the SYSTEM256 PS2 EEPROM  
    `32 1F C7 FA D6 EE F0 1C`  
    If signature does not match, game will lock.
